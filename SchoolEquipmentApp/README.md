# SchoolEquipmentApp (WPF)
Структура: `Models`, `Views`, `Services`, `Helpers`, `Data`, `SqlScripts`, `Resources`.

## Настройка
1. Выполните скрипт `SqlScripts/SchoolEquipmentDB.sql` в SQL Server.
2. Измените строку подключения в `Data/DbConnectionFactory.cs`.
3. Установите NuGet пакеты и запустите проект.
